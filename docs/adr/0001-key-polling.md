# ADR-0001：KEY1 使用5ms轮询

- 状态：已采纳（本次T1训练）
- 日期：2026-10-10
- 决策人：殷白玉；协助：Codex
- 关联需求：REQ-001、REQ-002

## 背景

T1只需用KEY1切换RGB。先选便于理解和排错的读取方法。

## 备选方案

| 方案 | 优点 | 代价 |
|---|---|---|
| 每5ms轮询 | 逻辑集中，容易打印和调试 | 周期唤醒，可能漏掉极短脉冲 |
| GPIO中断 | 事件到来时立即处理 | 需要处理回调与线程间通信，抖动仍需解决 |

## 决策

Codex给出两个方案后，殷白玉明确选择5ms轮询。理由是训练功能小，代码简单、便于调试。

## 后果

第一版只检测按下边沿，不加消抖，按课程安排用实测检查重复触发。轮询正确不代表实际按键没有抖动。后续要加消抖时，另行更新设计。
