# 总结排版检查

采用课程原DOCX模板作局部填写，正文和页眉项目名为编辑范围；其他OOXML包部件保持原样。个人三段文字来自殷白玉修改确认的版本，未恢复删去的段落。

技能自带render_docx.py在本机报缺少soffice.exe，未使用用户安装的LibreOffice。改用Word后台只读打开并导出PDF，再由工作区内置pypdfium2生成逐页图片，人工检查全页。PDF及PNG仅作内部排版检查，不是额外交付物。

统计口径：6个T1用例、6通过、0失败、0未执行；4个物理轮次，10+21+30+10=71次实际按下。4轮不是失败后的回归轮次。未消抖风险保留。非T1指定章节按教师训练说明保留模板，空白不是遗漏。

最终Word导出的10页均已逐页检查：中文、表格、分页无截断或越界，指定章节和个人原文完整。确认后未再改动DOCX。
